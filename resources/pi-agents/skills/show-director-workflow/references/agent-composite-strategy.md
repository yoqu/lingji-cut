# Agent Composite Strategy

## 三种执行策略

| 策略 | 适用条件 | 不适用条件 |
| --- | --- | --- |
| `motion-card` | 数据、关系、步骤、抽象观点或符号化事实已能独立讲清，真实素材不提供额外可见信息 | 口播需要来源特定证据，或真实环境、动作、对象、情绪对理解有独立价值 |
| `standalone-media` | 素材自身已完整承载动作、对象、场景或情绪，额外信息层只会重复 | 观众必须同时理解素材之外的比较、因果或关键数据 |
| `agent-composite` | 真实素材和信息层各自不可替代，并需要在同一时空中互相论证 | 只为丰富画面、装饰数据、填补空白或套用画中画 |

## 双重不可替代测试

先横向扫描相邻 cue 的叙事关系。若前一处提供来源特定的真实证据，后一处提供素材无法独立表达的解释、比较或结论，先判断它们是否需要合并成一个语义镜头；不要先固定分段，再把证据与解释拆开审计。

对每个组合候选分别回答：

1. 去掉素材，是否会失去无法由 Motion 等价承载的可见信息？`evidence` 必须是来源特定证据；`context`、`emotion`、`demonstration` 或 breath 镜头可以是相关且不误导的通用真实环境、动作、对象或情绪。
2. 去掉信息层，观众是否会失去素材自身无法表达的观点、数字关系、因果或阅读顺序？
3. 两者是否必须按口播节拍发生关系，而不是简单叠放？

前两项必须同时为“是”，第三项必须给出具体时序关系。任一项不成立就改选更简单的策略。该测试不产生素材或 composite 的数量、占比、连续段数和首尾限制；零个或多个都可以，但没有可执行 composite 时必须在草案顶层提交具体 `zeroCompositeReason`。

## 媒介角色与非误导边界

- `mediaRole="evidence"`：素材必须能核验到口播所说的特定人物、机构、产品、地点或事件。通用 B-roll 不能被包装成该事件现场。
- `mediaRole="context"|"emotion"|"demonstration"`：素材可以来自通用真实 B-roll，只要画面与当前叙事相关，且不会暗示它记录了并未记录的特定事实。`purpose="breath"` 通常对应 context 或 emotion。
- 采用理由必须基于检视画面，说明实际可见主体或动作、承担的媒介角色，以及为何不会误导。检索分只用于候选排序；低分不构成拒绝理由，高分也不构成采用依据。
- 不需要来源特定证据不等于不需要真实画面。先判断场景、动作、对象质感、情绪或留白是否提供独立叙事价值，再选择 Motion 或素材。

## Composition Intent

`compositionIntent` 只写叙事约束：

- `narrativeGoal`: 这一镜如何形成视觉论证。
- `focalPriority`: 观众第一眼和重音落点应该看什么。
- `temporalRelationship`: 素材与信息层何时建立、回应、让位和收束。
- `mustShow`: required 素材、不可改写的事实或必须可见的关系。
- `avoid`: 误导性证据、广告式陈列、重复信息和抢字幕等禁区。

不要写画中画、分屏、左右布局、坐标、CSS、蒙版形状或具体 Remotion 组件。制作 Agent 根据 intent 和冻结素材自行完成构图。

## Fallback

- `block`: required 素材缺失、失效、不可检视或真实性不确定时停止该镜头。事实证据默认选择此项。
- `standalone-media`: 仅当素材脱离信息层仍能准确承载本段核心语义。
- `motion`: 仅当去掉素材不会损失当前媒介角色承担的独立叙事价值，且符号化 Motion 能诚实表达。

任何退路都必须在草案中显式给出。运行时失败不能改变导演决策；只能按已批准 fallback 执行或进入 blocked。
