# 发布识别工作流

把任意本地工作目录识别成可发布草稿。成片路径和多比例封面由程序扫描，不经模型挑选。你只产出标题、简介、标签；封面提示词仅在没有可用封面且没有现成提示词时补。用户随后在发布台核对并一键上传；本流程不上传、不生成封面图。

## 原则

- 目录结构因项目而异。文案可能在 Markdown、JSON 或字幕里。先读 `detected.excerpts` 再决定。
- 常见文件只是线索，不是准入条件。遇到了就读内容，没遇到就换来源。不要按文件名规则判断。
- 不要编造文案事实。生成是补缺：能采用现成标题/简介/标签时不要重写。
- 不要挑选或改写成片、封面路径。这些字段由提交工具自动填入。

## 文案

- 优先采用摘录里已经写好的标题、简介、标签。
- 没有现成文案时，用口播、字幕或主题说明调用生成工具。
- 标题保持短、适合社交平台。

## 封面提示词

- 只生成提示词，不要调用任何出图能力。
- `detected.skipCoverPrompt` 为 true、已有封面或已有封面提示词时不要调用生成工具。
- 生成失败不要重试，直接校验提交。用户稍后可在发布台重画。
